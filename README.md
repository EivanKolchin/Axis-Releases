# Axis releases

Installers for [Axis](https://www.aroundaxis.co.uk).

This repository holds published builds only. It contains no source code;
Axis is proprietary and developed in a private repository.

## Downloads

Get the current build for your platform from
**[aroundaxis.co.uk/apps](https://www.aroundaxis.co.uk/apps)**, which always
points at the latest release here.

| Platform | Page |
| --- | --- |
| Android | [aroundaxis.co.uk/on-the-go](https://www.aroundaxis.co.uk/on-the-go) |
| Windows and macOS | [aroundaxis.co.uk/desktop](https://www.aroundaxis.co.uk/desktop) |

Individual files are also attached to each entry under
[Releases](../../releases), which is where the desktop app looks when it
checks for updates.
